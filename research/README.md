# Research knowledge base

Главный вход в накопленные исследования Microsonya — [`KNOWLEDGE.md`](KNOWLEDGE.md).

Документ собирает в одном месте:

- ограничения и provenance Telegram dataset;
- подтверждённые статистические результаты;
- практические решения для collector, segmentation и memory;
- результаты model/eval экспериментов;
- гипотезы, которые пока нельзя превращать в product rules;
- карту артефактов и следующий research backlog.

`out/` содержит сгенерированные CSV и исходный `summary.md`. Сырые
исследовательские scripts в текущем checkout отсутствуют; исторические версии
runner и расширенных отчётов сохранены в git history (commit `9ca4995`).
